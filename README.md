# 模块依赖分析器

纯静态网页工具：把脏写法的模块依赖清单贴进左侧（或拖入 `.txt`），点「分析」，
右侧用 SVG 画出**按被依赖方向分层**的依赖图、拓扑顺序、全部环清单与孤立模块。
双击 `index.html` 即可使用，无需构建、无第三方依赖。

## 输入语法（脏数据自动归一）

- 一行一条；箭头前后是“谁依赖谁”，箭头右边是**被依赖方**。
- 等价箭头全部归一：`->` `=>` `-->` `→` `⟶` `depends on` `:` `：`。
- 链式写法：`a -> b -> c` 解析为 `a->b`、`b->c`。
- 多目标：`a -> b, c；d`（半角/全角逗号、分号均可）。
- 模块名两侧的引号（单/双）与空白会剥掉；引号内空格保留（`"my mod"`）。
- 注释：`#`、`//`、`--` 到行尾；引号内的注释符号原样保留；`-->` 是箭头不是注释。
- 重复边自动合并并计数；没有箭头的非空行按“模块声明”处理（可逗号列多个）。

## 结果与规则（全部确定性，同输入必同输出）

- **强连通分量（SCC，Tarjan）**：缠成环的一坨当一个整体。
- **全部简单回路（Johnson 算法）**：
  - 自环 `a->a`、二元互指 `a<->b`（只算 1 条）都支持；
  - 同一条环换起点（`a->b->c->a` 与 `b->c->a->b`）用“字典序最小起点旋转”归一，只计一次；
  - 反向三环 `a->c->b->a` 是不同的边集，算另一条环；
  - 统计栏给出**环总数**；图上环面板最多展开 50 条，超出可一键展开并始终显示总数。
- **分层（有环也能分）**：SCC 缩点成 DAG，无出边的基础分量 `level=0`（画在最上），
  `level(c) = 1 + max(level(直接依赖))`，即按最长路径分层；
  同层分量按分量 key（内部最小模块名）字典序排，分量内部节点字典序排。
- **拓扑/构建顺序**：被依赖的先构建（level 从大到小读），同级字典序。
- **孤立模块**：从未出现在任何边两端的名字，图底部单列一区、单独一个标签页。
- **点击模块高亮**：
  - 绿色＝传递上游（沿箭头它会用到的，即“谁会牵连它”）；
  - 橙色＝传递下游（反向可达，即“它会牵连谁”）；
  - 金色＝所属循环组，组内成员互相算进上/下游，闭包隔着环也正确；
  - 点击虚线「循环组」标题弹窗列出组内环路径，点路径可在图上金色描出该环。

## 性能

1000 模块 / 5000 边 / 20 个故意构造的环：解析+SCC+Johnson+分层约 20–30ms，
含 SVG 全量渲染约 150–200ms（内置自测第 20 条断言 < 1000ms）。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `js/parser.js` | 注释剥离、箭头/多目标/引号归一、重复边合并 |
| `js/scc.js` | Tarjan 强连通分量（迭代实现，防大图爆栈） |
| `js/cycles.js` | Johnson 全简单回路枚举 + 旋转归一去重 |
| `js/layering.js` | SCC 缩点 DAG、最长路径分层、拓扑序、传递闭包 |
| `js/graph.js` | SVG 分层图渲染与高亮化 |
| `js/app.js` | 输入/拖放、面板、统计与交互组装 |
| `js/selftest.js` | 21 条断言（浏览器与 Node 均可运行） |

点右上角「运行自测」逐条查看 PASS/FAIL，失败时会写明期望与实际。
覆盖：单环/多环/自环/二元环/旋转去重/大环套小环/逗号多目标/引号名/
等价箭头/重复边/注释/孤立/右仅现不丢/闭包正确性（含跨环整体）/
有环分层/同层字典序/环总数/稳定性/脏数据综合/性能/空输入。
