# 模块依赖分析器

纯静态网页工具，直接用浏览器打开 `index.html` 即可（无需服务器、无外部依赖）。

## 用法

1. 左侧粘贴依赖清单，或把 .txt 文件拖进文本框，点「分析」。
2. 右侧 SVG 分层图：被依赖的模块在上层，依赖别人的在下层；滚轮缩放、拖拽平移。
3. 点击任意模块：高亮它的传递上游（谁会牵连它，橙色）与传递下游（它会牵连谁，绿色）；循环组作为整体高亮。
4. 点击「循环组」虚线框：环列表只显示该组的环；点击某条环：图上高亮环路径。
5. 图下方依次是：环列表（最多展开 50 条，超出报总数）、拓扑顺序（构建/阅读顺序）、孤立模块区。
6. 「运行自测」：21 条断言逐条列出通过/失败，失败会写明期望与实际。

## 支持的输入写法

- `a -> b`、`a: b`、`a => b`、`b <- a`、`b <= a`、`a：b`（等价归一）
- `a -> b, c，d、e`（逗号/中文逗号/顿号/分号多目标）
- `a -> b -> c`（链式）
- `# 注释`、`// 注释`（整行与行尾，引号内除外）
- `"带空格的模块名"`、`'引号'`（引号与两侧空白自动剥除）
- 单行模块名 = 孤立模块；重复边自动合并

## 规则（写死，保证同一文本两次分析结果一致）

- 环：Johnson 算法找全部基本环，自环与二元互指都算；按字典序最小节点旋转归一去重，换起点不重复计数。
- 分层：先求强连通分量（Tarjan），环缠成的分量作为整体「循环组」参与分层；层号 = 凝聚 DAG 上的最长路径（不依赖任何模块的为第 0 层，在最上）；同层按分量最小成员名字典序，组内成员按字典序。
- 闭包：在凝聚 DAG 上做传递闭包，环不影响闭包正确性。

## 代码结构

- `js/parser.js` — 文本解析与归一
- `js/graph.js` — SCC、全部环、凝聚图、闭包、分层、拓扑序
- `js/layout.js` — 分层坐标布局
- `js/render.js` — SVG 绘制与交互（缩放/平移/高亮）
- `js/selftest.js` — 21 条自测断言（含 1000 模块/5000 边/20 环 < 1s 性能用例）
- `js/app.js` — UI 串联
